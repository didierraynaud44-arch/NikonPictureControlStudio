Aide

Charger un dossier de photos

Dans le panneau Dossiers Photos (colonne de gauche), cliquez sur + Ouvrir. Choisissez le dossier contenant vos photos (RAW, TIFF, JPEG…) — Pixel RAW l'indexe et l'ajoute à votre arbre de dossiers.

Une fois indexé, le dossier reste disponible d'une session à l'autre : pas besoin de le réimporter à chaque lancement de l'application.

Pour un très gros dossier, un message « Indexation en cours » s'affiche le temps du traitement — inutile de s'inquiéter si ça prend quelques minutes sur une bibliothèque volumineuse.

Le mode Studio

C'est l'espace principal de retouche. Cliquez sur une photo dans l'arbre de gauche (ou utilisez les flèches ‹ › pour naviguer) pour l'ouvrir en grand.

Depuis le Studio, vous pouvez :

  • Ajuster les réglages Picture Control (exposition, contraste, netteté…)
  • Appliquer un profil Nikon (Standard, Vivid, Monochrome…)
  • Peindre des masques locaux (linéaires, radiaux, pinceau, ou masques IA Ciel/Sujet/Arrière-plan)
  • Corriger poussières et éléments indésirables avec le Tampon de duplication
  • Utiliser le module Monochrome avancé (mixeur 8 canaux, Lumière tamisée, Dodge & Burn)
  • Recadrer, redresser l'horizon, corriger la perspective
  • Noter vos photos (étoiles, Validée/Rejetée) et filtrer la Galerie

Tout ce que vous faites en Studio s'applique à la photo réellement sélectionnée dans votre bibliothèque — c'est votre espace de travail principal.

Le mode Gestionnaire de profils

Un espace totalement séparé du Studio, dédié à la création et au test de profils Picture Control Nikon (NP3/NPC), sans jamais toucher à la photo actuellement ouverte dans le Studio.

À l'ouverture de ce mode, aucune photo n'est chargée — c'est volontaire. Pour travailler dedans :

  1. Cliquez sur Importer un RAW (menu de gauche) pour charger une photo de test, propre à ce module.
  2. Réglez les curseurs comme vous le souhaitez.
  3. Exportez le profil obtenu (fichier NP3 ou NPC) pour le transférer plus tard sur votre appareil Nikon.
  4. Vous pouvez aussi importer un profil existant (NPC pour Z6 II/Z5/D780, ou NP3 pour Z6III/Z5II/Z8) et cliquer sur Aperçu sur cette photo pour voir son rendu avant de l'utiliser réellement.

Ce module est pensé comme un bac à sable : vous pouvez fabriquer, tester, réinitialiser autant de fois que nécessaire, sans jamais risquer de modifier la photo sur laquelle vous travaillez par ailleurs dans le Studio.

Passer du Studio au Gestionnaire de profils

Deux façons d'y accéder :

  • Le menu Fichier > Gestionnaire de profils pour Nikon
  • Le raccourci correspondant dans la barre de menu du haut (si affiché)

Pour revenir au Studio, cliquez simplement sur Studio dans la barre de menu.

Le menu Programmes externes

Permet d'ouvrir la photo actuellement affichée dans un autre logiciel (Photoshop, Exposure X7, etc.), avec vos réglages Picture Control déjà appliqués (export automatique en TIFF traité, pas la RAW brute).

Avant la première utilisation, il faut déclarer au moins un programme :

  1. Allez dans Fichier > Paramètres.
  2. Dans la section Programmes externes, cliquez + Ajouter, donnez-lui un nom (ex : « Photoshop »), puis indiquez le chemin de son exécutable (.exe) via le sélecteur de fichier.
  3. Vous pouvez déclarer plusieurs programmes.

Pour l'utiliser : dans le Studio, cliquez sur Ouvrir avec (en haut à droite) et choisissez le programme dans la liste. Le fichier généré est automatiquement enregistré dans le même dossier que la photo d'origine, et réapparaît dans votre arbre dès que vous l'enregistrez depuis le logiciel externe.

Si aucun programme n'est déclaré, ce menu vous invite à vous rendre dans Paramètres pour en configurer un.

Le menu Exporter

Génère un fichier JPEG ou TIFF de votre photo traitée, à la résolution réelle du capteur (pas l'aperçu réduit du Studio).

Réglages disponibles :

  • Qualité/compression (100 % = qualité maximale)
  • Format (JPEG ou TIFF)
  • Espace colorimétrique : sRGB (par défaut, le plus répandu) ou ProPhoto RGB (gamme de couleurs plus large, pour un usage professionnel/impression avancée)
  • Cadre (optionnel) : ajout d'une bordure blanche ou noire autour de la photo, sans jamais rogner l'image

Le menu Impression

Ouvre la boîte de dialogue d'impression native de Windows — c'est volontaire : elle seule donne accès aux réglages avancés de votre imprimante (bac papier, type de papier, gestion des couleurs) via le bouton Propriétés/Préférences du pilote.

Étapes :

  1. Cliquez sur Impression dans le Studio.
  2. Choisissez votre imprimante dans la boîte de dialogue Windows.
  3. Cliquez sur Propriétés pour régler le bac d'alimentation et le type de papier (indispensable pour une imprimante photo comme la Canon PRO-300, par exemple).
  4. Lancez l'impression.

L'image envoyée à l'imprimante est toujours la version pleine résolution, avec tous vos réglages Picture Control déjà appliqués — identique à ce que produirait un export JPEG/TIFF.

Remerciements

Pixel RAW n'existerait pas sans plusieurs projets open source, et leurs auteurs méritent d'être cités :

  • nikon-flexible-color-picture-control (ssssota) — le point de départ de ce projet, pour la lecture/écriture des profils Nikon.
  • LibRaw / libraw-wasm — pour le décodage RAW pleine résolution.
  • Sharp — pour le traitement et l'export des images.
  • ExifTool (Phil Harvey) et exifr — pour la lecture des métadonnées.
  • MobileSAM et le projet de segmentation du ciel (xiongzhu666) — pour les masques intelligents.
  • NAFNet (Megvii Research) — pour le débruitage neuronal.
  • Lensfun — pour la base de données de correction d'objectifs.
  • ONNX Runtime (Microsoft) — pour l'exécution des modèles d'intelligence artificielle.
  • Electron — pour le socle applicatif.

Merci à toutes celles et ceux qui ont rendu ce travail possible en le partageant librement.

La liste complète et détaillée des licences est disponible dans le fichier THIRD-PARTY-LICENSES.md du dépôt GitHub du projet.

Paramètres

"Ouvrir avec" génère un TIFF sans perte (réglages + masques + retouches appliqués) dans le dossier de la photo, puis lance le programme dessus. Plusieurs programmes peuvent être déclarés.

Espace colorimétrique utilisé par défaut lors d'un export (conversion ICC réelle, pas une étiquette). Pré-remplit la modale d'export, modifiable à chaque export.
